# Monitoring

## Signals
Watch `mcp`/`rag-search` errors, version conflicts, missing/ambiguous anchors, batch budget outcomes and explicit hybrid fallbacks. Record timings and response sizes without logging note bodies, tokens or API keys.

## Validation
CI covers protocol and database behavior. Compare text/semantic/hybrid output and ownership on staging after deployment; tests alone do not prove a live client OAuth round-trip.

## Status
No runtime performance or deployment claims yet. Claude's explicit approval and exact-head CI are merge gates.
