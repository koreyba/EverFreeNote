# Mobile editor layout monitoring

## Key Metrics
Validate scroll responsiveness, bottom-content reachability, software keyboard viewport fit, and command selection after release.

## Monitoring Tools
Existing browser console/error handling and Allure component reports. No added telemetry.

## Incident Response
Record device, orientation, keyboard visibility and reproduction steps for any layout regression; rerun the corresponding mobile browser scenario. Native-device observations remain distinct from simulated viewport evidence.
